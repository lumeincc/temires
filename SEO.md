# SEO для сайта Темирэнергострой

Поисковики берут описание сайта из `<head>` страницы. Код блока T123 попадает в `<body>`, поэтому теги `<meta>` внутри блока не работают. Title и description нужно заполнить в настройках страницы Тильды.

## 1. Настройки страницы → SEO

**Заголовок (title):**
Печи-инсинераторы, металлоконструкции, БМЗ | Темирэнергострой

**Описание (description):**
Казахстанский производитель печей-инсинераторов «Веста Плюс», металлоконструкций и блочно-модульных зданий. Доставка и монтаж по РК. Расчёт за рабочий день.

**Ключевые слова (keywords)** — если в Тильде есть такое поле. Google их не учитывает, Яндекс почти не учитывает:
печь инсинератор, инсинератор купить, печь для сжигания отходов, утилизация биологических отходов, печь для сжигания падежа, инсинератор для птицефабрики, ветеринарный инсинератор, Веста Плюс, металлоконструкции Казахстан, изготовление металлоконструкций, блочно-модульные здания, БМЗ Казахстан, Темирэнергострой

## 2. Настройки страницы → Facebook / соцсети (превью ссылки в WhatsApp, Telegram, Instagram)

- Заголовок: Темирэнергострой — печи-инсинераторы, металлоконструкции, БМЗ
- Описание: Собственное производство в Казахстане. Печь «Веста Плюс» сжигает отходы при 1100–1200 °C прямо на вашей территории.
- Картинка: фото печи, 1200×630 px

## 3. Уже в коде блока

`<script type="application/ld+json">` — структурированные данные schema.org: компания (телефон, почта, Telegram, Instagram, регион) и продукт «Веста Плюс» с характеристиками. Их читают Google и Яндекс в любом месте страницы.

Проверка после публикации: https://validator.schema.org/ — вставить адрес сайта.
