# Темирэнергострой — сайт на Тильде

| Файл | Что это |
|---|---|
| `tilda/temires-autumn.html` | Осенняя версия. Весь файл целиком вставляется в блок **T123 «HTML-код»** вместо старого кода. |
| `preview/index.html` | Превью для просмотра. Собирается из файла выше командой `node preview/build.mjs`, фото в нём заменены заглушками. |

## Как обновить сайт

1. Открыть страницу в Тильде → блок T123 → «Контент».
2. Сохранить старый код к себе (на случай отката).
3. Вставить содержимое `tilda/temires-autumn.html` целиком, сохранить, опубликовать.

Форма заявки осталась прежней (те же `formservices`, имена полей и классы Тильды), поэтому заявки будут приходить туда же, куда и раньше.
